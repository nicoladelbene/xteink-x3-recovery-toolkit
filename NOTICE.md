# Notices and attributions

## Not affiliated

This is an independent, personal project. It is **not affiliated with, endorsed by, or
supported by** the CrossPoint Reader project, CrossInk, or XteInk. "CrossPoint", "CrossInk"
and "XteInk" are used only to say which device and firmware these tools were tested with.
Report firmware problems to the firmware's own issue tracker, not there on behalf of this repo.

## What this repository does not contain

- No firmware binaries. `firmware-check` validates a file you download yourself from the
  official release page; only published SHA-256 digests are quoted.
- No CrossPoint source code. Behaviour notes cite file paths and line numbers at public tags.
- No books, book covers, book metadata, reading-progress files, device settings or card images.
  Reconstruction results are reported per anonymous `book-NN` with rounded sizes only.
- No third-party wallpapers. The wallpaper counts by source are statistics only.
